# 经验设计工具 — 主任务计划

> **项目**:经验设计工具(可视化检索、浏览、设计修改)
> **计划文档**:[doc 20](../docs/mvp/20-experience-design-tool.md)
> **状态**:进行中
> **创建时间**:2026-09-09

---

## 一、项目目标

构建一个 Web 应用,提供经验库的可视化检索、浏览、设计修改能力:

| 能力 | 说明 |
|------|------|
| 列表浏览 | 经验库列表,展示 id + 简述 + 元数据 |
| 模糊搜索 | 按名称 + 简述信息模糊匹配(MVP 不含向量搜索) |
| 详情展示 | 经验三段式结构 + 元数据 + DAG 可视化 |
| 基础信息编辑 | 经验 id/description/tags 等元数据直接编辑 |
| DAG 可视化 | 经验 DAG 图形化展示(只读,不支持 UI 拖拽编辑) |
| LLM 对话编辑 | 通过 LLM 对话理解用户意图,映射到 XML 节点/DAG 概念节点的 CRUD 操作 |

---

## 二、阶段总览

```
Phase F1: XML 中间定义层 + 编译器(纯后端,无 UI)
   ↓ Gate-F1
Phase F2: 元数据 + 文件系统存储 + 检索(纯后端,无 UI)
   ↓ Gate-F2
Phase F3: 可视化浏览(Web 应用,只读)
   ↓ Gate-F3
Phase F4: LLM 对话驱动编辑(Web 应用,可写)
   ↓ Gate-F4
```

| Phase | 目标 | Gate 标准 | 子任务数 | 估算 |
|-------|------|-----------|----------|------|
| F1 | XML schema + 解析 + 校验 + 编译器 | XML→L3 编译合法 + 端到端执行 | 6 | 4-6d |
| F2 | 元数据 + 文件系统存储 + 模糊搜索 | 9 条经验持久化 + 可搜索 | 7 | 4-5d |
| F3 | Web 应用只读浏览 | 列表+搜索+详情+DAG 可视化 | 9 | 4-5d |
| F4 | LLM 对话驱动编辑 | 对话→操作→XML CRUD→三层验证→入库 | 12 | 6-9d |

**关键路径**:F1.1 → F1.2 → F1.3 → F1.4 → F4.6 → F4.7 → F4.12
**总估算**:16-20 个工作日(关键路径)

---

## 三、依赖关系

```
F1(XML 层 + 编译器)── 地基,不可压缩
  ├── F2(文件存储 + 检索)── F1 完成后
  ├── F3(Web 浏览)── F1 + F2 完成后
  └── F4(LLM 编辑)── F1 + F2 + F3 完成后
```

**并行窗口**:
- F1 ∥ F2.1(元数据 schema 不依赖 F1)
- F3.1(后端)∥ F3.2(前端骨架)
- F4.1(操作指令 schema)∥ F4.2(LLM 客户端)可早开工

## 五、技术栈

| 层 | 技术 |
|----|------|
| 前端 | React 18 + Vite + Tailwind + Zustand |
| DAG 可视化 | React Flow(只读模式) |
| XML 查看 | Monaco Editor(只读) |
| 流程图 | Mermaid.js |
| 后端 | Fastify + TypeScript |
| XML 解析 | fast-xml-parser + Zod |
| 经验库存储 | 文件系统(XML + metadata.json) |
| LLM | LiteLLM 代理(`http://127.0.0.1:4000` + `LITELLM_MASTER_KEY`) |
